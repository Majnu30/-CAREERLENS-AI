# 🎯 CareerLens AI

## AI-Powered Career Intelligence & Recruitment Platform

CareerLens AI is an AI-powered platform designed for both job seekers and recruiters.

## 👨‍💻 Job Seeker Dashboard

Features:

- Resume Analysis
- Job Analysis
- Job Fraud Detection
- AI Job Matching
- Skill Gap Analysis
- Career Roadmap
- Application Tracking
- AI Career Assistant

## 🧑‍💼 Recruiter Dashboard

Features:

- Job Creation
- Bulk Resume Upload
- AI Resume Parsing
- Candidate Ranking
- Custom Top-N Selection
- Candidate Filtering
- Candidate Comparison
- Shortlisting
- Recruitment Pipeline
- Hiring Analytics
- AI Recruiter Assistant

## 🧠 AI Components

The project will use:

- Natural Language Processing
- Resume Information Extraction
- Semantic Job Matching
- Machine Learning based Fraud Detection
- Candidate Ranking
- Skill Gap Analysis
- Generative AI Career Assistance

## 🛠️ Technology Stack

- Python
- Streamlit
- Scikit-learn
- NLP
- Sentence Transformers
- Pandas
- SQLite
- Plotly

## 🚀 Project Status

Currently under development.

The system is being developed incrementally, beginning with the application interface and followed by the AI/ML pipeline.

## 👨‍🎓 Project Type

Final Year Project
